# 🎫 Vanilla Land • Discord Bot (Тикеты + Модерация)

Оптимизированный и функциональный Discord-бот службы поддержки и модерации.
Полностью адаптирован для бесплатного тарифа хостинга **bot-hosting.net** (потребляет менее 50 МБ RAM из 256 МБ).

---

## 🚀 Возможности бота:

### 1. 🛡 Модерация (префиксы `!` и слэш `/`)
- **`!mute @user [время] [причина]`** (или `/mute`):
  - Выдает роль мута (`1472669326237761586`) и накладывает таймаут Discord.
  - Понимает форматы времени: `10m`, `30m`, `2h`, `1d`, `7d` (по умолчанию 15 мин).
  - **Поддержка ответа на сообщение**: можно просто ответить (Reply) на сообщение нарушителя командой `!mute 30m спам` без упоминания!
  - Отправляет нарушителю подробное уведомление в ЛС.
  - Сохраняет мут в базе данных и автоматически снимает его по истечении времени.
- **`!unmute @user [причина]`** (или `/unmute`):
  - Снимает роль мута и таймаут, удаляет запись из базы и уведомляет пользователя в ЛС.
- **`!kick @user [причина]`** (или `/kick`):
  - Отправляет уведомление с причиной в ЛС нарушителю и выгоняет с сервера.
- **`!ban @user [причина]`** (или `/ban`):
  - Отправляет уведомление в ЛС нарушителю и блокирует на сервере.
- **`!unban <ID> [причина]`** (или `/unban`):
  - Разблокирует пользователя по его Discord ID.

### 2. 🎮 Инфо о сервере:
- **`!ip`** или **`!айпи`** (а также `/ip`, `/айпи`):
  - Показывает IP сервера: `vanillaland.ru-mc.ru`
  - Дает ссылку на Telegram: `https://t.me/vanilandes`

### 3. 📩 Система тикетов:
- Создание тикетов в один клик по персистентной кнопке `📩 Создать тикет`.
- Закрытие через кнопку `🔒 Закрыть тикет` с модальным окном ввода причины.
- Сохранение логов переписки в `.txt` и отправка в ЛС игроку.
- Команды `!add @user` и `!remove @user` внутри тикетов.
- Автоматическое закрытие неактивных тикетов через 24 часа.

## 📦 Развертывание на bot-hosting.net

1. Запакуйте в ZIP-архив:
   - `cogs/`
   - `main.py`
   - `bot.py`
   - `config.py`
   - `database.py`
   - `requirements.txt`
2. Загрузите архив на **bot-hosting.net** (выберите Python).
3. В разделе **Variables** укажите переменные:
   - `DISCORD_TOKEN`
   - `PANEL_CHANNEL_ID`
   - `MOD_ROLE_IDS`
   - `MUTE_ROLE_ID` (`1472669326237761586`)
4. Включите **Server Members Intent** и **Message Content Intent** в [Discord Developer Portal](https://discord.com/developers/applications).
5. Запустите бота!
